# Local Hodge Lean Variants 2026

Local Lean 4 files from Drive/attachments, pushed for public provenance.

- `OpenCase.lean`: Minimal skeleton for the statement that every extra rational (2,2)-class on a general fourfold is algebraic. The theorem leaves the existential witness unsolved.
- `NewHost.lean`: Host certificate for the homogeneous Fermat quintic fourfold F5 in P^5 (Euler relation, Jacobian isolation at origin). Notes h^{3,1}=120. Not a Hodge proof.
- `CubicFourfoldHodge.lean` / `-2.lean`: Axiomatic skeleton for the Zucker (1977) / Beauville–Donagi correspondence for smooth cubic fourfolds.
- `FermatQuinticJacobian.lean`: Jacobian criterion certificate for Fermat quintic smoothness.
